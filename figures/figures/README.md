# Figures

This directory contains figure resources associated with the computational workflow presented in the manuscript.

To avoid duplication of journal-formatted publication materials, the final publication figures are not distributed in this repository.

Where appropriate, this directory may include:

- workflow schematics
- computational pipeline diagrams
- model evaluation visualizations
- reproducible example figures
- figure-generation scripts

The publication figures appearing in the manuscript should be consulted in the published article.

Scripts used to generate reproducible visualizations are provided in the corresponding analysis modules where applicable.
