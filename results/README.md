# Results Directory

## Purpose

This directory stores analytical outputs generated from the reproducible computational workflow described in the manuscript:

**AI-Driven Pharmacovigilance and Molecular Profiling of Fluoroquinolone-Associated Cardiotoxicity in the UAE**

The files contained within this directory represent analysis outputs rather than raw data.

# Expected Outputs

The repository organizes analytical outputs into the following categories:

| File | Purpose |
|------|----------|
| descriptive_statistics.csv | Summary characteristics of analytical cohort |
| signal_detection_results.csv | Pharmacovigilance disproportionality analyses |
| regression_results.csv | Multivariable logistic regression results |
| ml_performance_metrics.json | Machine-learning performance metrics |
| shap_values.csv | Explainable AI feature importance |
| ddi_network_results.csv | Drug-drug interaction network summary |
