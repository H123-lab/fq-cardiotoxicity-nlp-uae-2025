# Methodology Notes

This repository accompanies the manuscript:

**AI-Driven Pharmacovigilance and Molecular Profiling of Fluoroquinolone-Associated Cardiotoxicity in the UAE**

The analytical workflow integrates:

- pharmacovigilance
- statistical analysis
- explainable artificial intelligence
- natural language processing
- drug–drug interaction network analysis
- geospatial analysis
- molecular docking
- structure–activity relationship analysis
- ADMET prediction

The computational workflow follows the order described in the manuscript Methods section.
