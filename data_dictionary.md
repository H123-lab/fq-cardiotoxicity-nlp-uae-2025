## 📁 Restricted MOHAP-derived dataset

The primary MOHAP-derived dataset used in the study is a restricted third-party
dataset and is therefore not distributed in this repository.

The following schema documents the variables used by the analysis pipeline.
It is provided for methodological transparency and reproducibility by authorized
data users.

| Column | Description |
|---|---|
| Prescription_ID | Internal record identifier; not publicly distributed |
| Year | Year of prescription/reporting |
| Facility | Healthcare institution or facility category, subject to data-access restrictions |
| Patient_Age | Patient age or age category, subject to source-data access conditions |
| Patient_Gender | Patient sex/gender field, subject to source-data access conditions |
| Fluoroquinolone | Fluoroquinolone exposure |
| Dosage_mg_day | Daily dose where available |
| Duration_days | Exposure duration where available |
| Co_Medications | Concomitant medications where available |

> **Access restriction:** The underlying MOHAP-derived records are not included
> in the public repository. This schema does not constitute redistribution of
> the source dataset.
