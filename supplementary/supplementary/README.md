# Supplementary Materials

This directory contains supplementary resources associated with the computational workflow described in the manuscript.

To avoid duplication of publisher-formatted supplementary files during peer review and publication, the journal-formatted Supplementary Materials are not distributed in this repository.

Where appropriate, this directory may contain:

- supplementary datasets
- software configuration tables
- computational parameter tables
- workflow documentation
- reproducibility resources
- example outputs generated from the computational pipeline

The final journal-formatted Supplementary Materials should be consulted alongside the published article.

All computational settings referenced in the manuscript are documented within the corresponding source code and software configuration files provided in this repository.
