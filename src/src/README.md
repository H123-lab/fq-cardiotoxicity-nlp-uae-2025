# Source Code Directory

## Purpose

This directory contains the reproducible analytical scripts used for the study:

"AI-Driven Pharmacovigilance and Molecular Profiling of Fluoroquinolone-Associated Cardiotoxicity in the UAE"

The source code implements the complete analytical workflow including:

- Data preprocessing
- Pharmacovigilance signal detection
- Statistical analysis
- Machine learning modelling
- Explainable artificial intelligence
- Drug-drug interaction analysis
- Geospatial analysis
- Molecular computational analysis


---

# Analytical Workflow

The computational pipeline follows:

Raw Data

Data Harmonization

↓

# Reproducibility Principles

All analyses should be generated through code rather than manual modification.

The scripts are designed to:

- Preserve analytical transparency
- Maintain manuscript-code consistency
- Support independent reproduction
- Document computational decisions


---

# Data Protection

No restricted healthcare datasets are included.

Sensitive datasets must remain local and are excluded through `.gitignore`.

Only:

- Processing logic
- Analytical workflows
- Documentation
- Non-sensitive outputs

are maintained in this repository.
